特性

少即是多，但不是少到空

Ink 只做必要的抽象。所有组件共享同一套令牌，改一处，全站生效。

语义令牌

颜色、间距、圆角、动效全部收口到 CSS 变量，没有魔法数字散落在样式里。

组件齐全

按钮、分段、芯片、开关、进度、消息条、对话框，覆盖日常界面九成场景。

浅色深色

内置两套主题，跟随系统切换。所有组件在两种模式下都经过对比度校验。

零依赖

不依赖任何框架、不引入外部字体。图标全部内联 SVG，离线也能用。

动效克制

只保留两档时长：160ms 和 320ms。不炫技，只做事。

中文友好

字体栈优先中文黑体，行高、字距针对中文重新调过，不照搬西文比例。

快速开始

三步，跑起来

1

获取源码

从 GitHub 克隆仓库，或直接下载 ZIP 包。

2

引入样式

把 style.css 和 fonts 文件夹放进你的项目，在主入口引入一次。

3

写标签

用语义化的 class 名，不需要任何构建工具，打开就能用。

terminal 
# 第一步：克隆仓库
git clone https://github.com/wud1700722-rgb/ink-design.git

# 第二步：在你的 HTML 入口引入 CSS
<link rel="stylesheet" href="./ink/style.css">

# 第三步：直接写 Ink 标签
<button class="ink-btn ink-btn--primary">
  开始使用
</button>
